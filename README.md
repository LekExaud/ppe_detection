# PPE Detection using YOLO

This project uses the YOLO object detection framework to identify Personal Protective Equipment (PPE) such as helmets, vests, and safety boots in real-time or from images.

## 📂 Project Structure
* `PPEDetection.py` - The main Python script to run the detection model.
* `ppe.pt` - Pre-trained YOLO model weights for PPE detection.

## ⚙️ Requirements
* Python 3.x
* Ultralytics (YOLO)
* OpenCV

## 🚀 How to Run
1. Install dependencies:
   ```bash
   pip install ultralytics opencv-python
   ```
2. Run the detection script:
   ```bash
   python PPEDetection.py
   ```
